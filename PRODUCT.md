# vanTilburg Cards

Reusable Home Assistant overview cards extracted from an existing household dashboard. Preserve the incumbent appearance and interactions while replacing duplicated inline CSS/JavaScript with typed configuration, tests and versioned releases.

Audience: household dashboard users and maintainers. Main tasks: scan room temperature/light status, storage charge and collection day; open a room/house/waste popup to use existing controls.

Scope: five configurable cards (room, house, waste, energy group and power), shared palettes, visual settings editors, and an embedded popup with repeated sections containing ordinary Lovelace cards. Actual device control belongs to the child cards. No backend integration, entity renaming, device actions during validation, or private household configuration in this repository.

Visual authority: user-supplied overview and Bedroom popup screenshots from the existing dashboard. This is extraction, not redesign.
